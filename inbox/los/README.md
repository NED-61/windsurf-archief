# inbox/los

Losse bestanden die je in een gesprek aanlevert (uitslag, foto of video). Die worden direct verwerkt en daarna ongewijzigd verplaatst naar `archive/<scope>/<jaar>/<evenement>/`.

Alleen een link? Die wordt ook geregistreerd, maar sla de pagina bij voorkeur op als bestand (Ctrl+S als html, of afdrukken naar pdf), want een webpagina kan verdwijnen.
